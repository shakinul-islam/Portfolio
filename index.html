EliteTalk Details

EliteTalk — Real-Time Communication Platform

EliteTalk is a full-stack, cross-platform real-time communication application developed as part of an industrial training project. The application focuses on secure communication, real-time messaging, multimedia sharing and AI-powered interaction.

It supports real-time messaging with Sent, Delivered and Seen status, typing indicators, secure message requests and access control. Users can share images, videos and documents through Cloudinary.

The application also includes an AI Chat Assistant powered by Groq API and Llama 3.3 70B with support for both English and Bengali. Additional features include swipe-to-reply, emoji reactions, message deletion and real-time notifications.

AI Expense Analyzer

AI Expense Analyzer — Smart Personal Finance

AI Expense Analyzer is an AI-powered personal finance management application designed to simplify expense tracking, financial analysis and budget management.

Its Smart AI Entry allows users to enter transactions naturally, such as "500 burger", while the AI identifies the transaction amount and category automatically.

The application also provides an AI Financial Assistant that analyzes users' financial data and provides personalized spending insights and recommendations. Budget monitoring and real-time notifications help users stay aware of their spending limits.

The backend is built with Node.js and Express.js, using MongoDB Atlas for data storage. Authentication is secured using JWT and bcrypt, while Groq models are integrated for AI-powered functionality.

Dokaner Hisab

Dokaner Hisab — Smart Grocery POS & Shop Management

Dokaner Hisab is a smart Grocery POS and Shop Management application built with Flutter and Dart to simplify daily retail operations.

The application provides POS billing with cart management, automatic stock deduction and support for multiple units such as Pcs, Kg and Liters. It also includes inventory management and purchase history.

Business owners can manage customer dues through Due Khata, track expenses and monitor profit/loss, monthly costs and net revenue through interactive financial analytics and charts.

Firebase Authentication and user-isolated Firestore Security Rules are used for secure data management. Cloudinary is integrated for shop logo/image uploads, while local notifications and offline Firestore persistence improve usability.

Contactless Dining SaaS

Contactless Dining SaaS — Restaurant Management Platform

Contactless Dining SaaS is a cloud-based restaurant management platform designed around a QR-based, zero-install customer ordering experience using a Progressive Web App (PWA).

Customers can scan a QR code and place orders without installing an application. Orders are synchronized in real time between Customer, Waiter and Kitchen interfaces using Firebase Cloud Firestore.

The responsive admin portal provides menu management, multi-image menu support, sales analytics and role-based access for Super Admin, Admin, Waiter and Kitchen users.

OneSignal Web SDK is used for real-time browser notifications with Cloudflare proxy support. Cloudinary manages menu images, while GitGuardian is used for API security and secret-leak monitoring.

The platform also supports bKash and Nagad payment tracking through Send Money, where customers submit their transaction ID for verification and tracking.

Flutter Dart Firebase Firestore PWA OneSignal Cloudflare Cloudinary GitGuardian bKash Nagad
